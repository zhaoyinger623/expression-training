## 本阶段修复

- 将读取响应正文纳入前端异常处理，避免正文超时或非 JSON 响应直接显示浏览器英文错误。
- 修正 Turbo 严格环境模式过滤后端运行变量的问题，支持根目录启动时的环境覆盖；前端环境文件变化会使构建缓存失效。
- 统一忽略 .env 的各环境变体，保留可提交的 .env.example 模板。

## 尚未覆盖的范围

- 真实人声、背景噪声、不同口音及连续多天使用的识别与评分质量。
- Chrome WebM 已验证录制和上传，但本次真实 Qwen 样本是 WAV，没有额外消耗授权调用测试 WebM 解码。
- Safari、Firefox 和移动设备原生麦克风未做实机验收。
- 尚未部署公网；当前无账户鉴权，后端默认只监听 127.0.0.1。

后续体验时，可先用本机 Chrome 完成一次正常作答及同题重答，听取真实人声的反馈，再决定是否调整提示词或兼容其他浏览器。

## v0.4.0：Vercel / IndexedDB 适配

- `pnpm build`：前后端类型检查和生产构建通过。
- 静态核对：后端无 SQLite 依赖或历史读写入口，round=2 不查询服务器历史；前后端统一 4 MiB 录音限制，metadata 16 KiB；函数时限需在 Vercel 控制台设为 150 秒（Fluid Compute 默认 300 秒也足够），CORS 使用配置的精确来源。
- 历史改为 IndexedDB，写入以事务 complete 为成功依据；保存失败不丢弃页面反馈，仅重试本地写入。
- 未运行新增自动化或浏览器测试，未调用真实 AI，未执行 Vercel 云部署；刷新恢复、浏览器存储权限失败和云端端到端体验仍需实际检查。前面的 R1–R8 记录对应当时版本。

- 部署反馈修复：删除 apps/api/vercel.json 中无法匹配的 functions.src/main.ts 配置，改用项目默认时限；配置 JSON 与 Git 差异检查通过，云端重新部署结果待确认。

- TS2688 修复：使用临时目录配置 extends 后端 tsconfig 的编译方式，在修改前复现缺少 node 类型的错误；明确 typeRoots 后同一编译退出码为 0，pnpm build 通过。未运行自动化测试或追加真实 API 调用；云端构建结果待确认。
